# BOX

Espaço de trabalho organizado em salas.

## Estrutura

- SALAS — espaços de trabalho isolados
- ARQUIVOS — arquivos gerais
- LOGS — registros gerais

## Salas

- _01
- _02
- _03

## Regra de acesso

Conhecer o nome ou caminho de uma sala não concede acesso.

O acesso será controlado posteriormente por uma camada de API e autorização.

## Princípio

BOX → SALA → ARQUIVOS → LOGS → API → AGENTE
